# Skaz Online Auto — экспериментальная версия 0.1.0

Отдельный форк плагина Skaz Online для Lampa с автоматическим выбором источника и озвучки. **Не заменяет и не меняет Amedia.**

## Установка
В Lampa откройте **Настройки → Расширения → Добавить плагин** и вставьте адрес:

`https://vanimusic6-sudo.github.io/Lamp.js/skaz-online-auto.js`

После добавления перезапустите Lampa. В меню настроек появится **Skaz Online Auto · 0.1.0**.

**Не устанавливайте эту сборку одновременно с другими копиями `onlines.js` / `o.js` / Onlyskaz**, иначе несколько плагинов могут конфликтовать из-за `window.onlyskaz_plugin`, `lampacskaz` и общих хранилищ. Amedia можно оставить.

## Реализовано
- **Автоматический балансер:** рейтинг известных источников плюс измеренный отклик успешно отработавших источников; источники с ошибкой временно исключаются, пользователю остаётся ручной выбор.
- **Автоматическая озвучка:** профессиональная и многоголосая озвучка имеют приоритет над любительской/оригиналом; вручную выбранная озвучка сохраняет приоритет.
- **Качество:** авто (лучшее доступное), 1080p, 720p, 480p; поддержка источников с объектами `quality` и резервной ссылкой формата ` or `.
- **Один клик:** после открытия Online начинается попытка воспроизведения выбранного фильма/серии без обязательного ручного выбора источника или озвучки.
- **Продолжение:** сортировка серий по номеру, выбор последней начатой серии, переход к следующей при завершённом просмотре (если Lampa вернула достоверный `Timeline.percent`).
- **Android:** если Android-мост доступен, он используется автоматически. Соседние серии разрешаются до открытия плеера (максимум две, суммарно не дольше 4,5 секунд). Передаются только обычные URL, без JS-функций и внутренних ссылок `method:call`. Штатный `playlist_next` включается через AndroidJS.
- **Браузер:** используется встроенный Lampa. Исходная поддержка RCH / запросов Skaz сохранена.
- **Сохранность функционала:** авторизация, регистрация устройства, подписка, рекламные интеграции, поиск по балансерам, настройки Skaz и субтитры остались из исходной версии.
- **Обложки:** не создаётся URL вида `.../undefined`; если постера серии нет, берётся фон карточки фильма/сериала.
- **Отдельные настройки:** все новые параметры под ключами `skaz_smart_*`, отдельное отображение версии.

## Что пока не гарантируется
1. **Это архивная копия Skaz Online**, опубликованная сторонним архиватором в мае 2026 года. Текущий исполняемый файл `skaz.tv/onlines.js` не удалось получить напрямую. Изменившиеся API, подписка или авторизация Skaz могут потребовать синхронизации с актуальным исходником.
2. **Не тестировалось на реальном Android TV.** Наличие очереди в JSON не означает, что выбранный сторонний видеоплеер реализует кнопки Previous/Next. В проверенном Android-коде Lampa разные плееры получают разные Intent extras; VLC и обычный Just Player могут получать только один URL.
3. **Истечение подписанных ссылок.** Для длинных серий подготовленные ссылки соседних эпизодов могут истечь. У Android нет универсального канала обратного вызова, позволяющего всем внешним плеерам заново запросить ссылку.
4. **Браузерные CORS/HTTP ошибки.** JS-плагин не может обойти правила CORS CDN. Стандартный браузер использует встроенный HLS Lampa и доступные сервером способы авторизации.
5. **Не является полной копией Amedia:** защита CDN и потоковые токены Amedia не переносились (это другой серверный API). Общие UX-возможности перенесены, но ядро и протокол Skaz Online сохранены.
6. Существующий Skaz Online использует RCH — сервер может отправлять динамические команды клиенту. Устанавливайте только из доверенного репозитория и только при понимании этой особенности.

## Происхождение и тесты
- Архивный исходник: https://github.com/voipoddsns/voipoddsns.github.io/blob/main/plugins/lampa_plugins/o.js
- Исходная разработка: Skaz / Onlyskaz (`skaz.tv/onlines.js`).
- Собственная сборка: `skaz-online-auto.js`.
- Автотесты: `tests/skaz-online-auto.test.cjs`, GitHub Actions `Skaz Online Auto checks`.
- Ни `amedia-android.js`, ни `trailer.js` не изменены.

## Возврат к оригиналу
Удалите `skaz-online-auto.js` в меню Расширения и установите обратно официальный URL Skaz Online. Настройки этой экспериментальной версии не удаляют и не перезаписывают параметры Amedia.
