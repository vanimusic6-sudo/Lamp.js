# Amedia / Capsule Online — критический аудит (18.11.2026)

## Объект и ограничения
- Основной файл: `capsule-online.js`, ветка `main` репозитория `vanimusic6-sudo/Lamp.js`.
- Проверены встроенный онлайн-движок, автоматический подбор, настройка интерфейса, обработка ошибок, границы интеграции с каталогом Amedia и встроенным/Android-плеером.
- Встроенный транспорт фильмов содержит большой **обфусцированный** код Skaz. Результаты статического аудита не доказывают безопасность либо корректность каждой его внутренней ветки. Тестирования на реальном ТВ/приставке и реальных потоках в этой проверке нет.

## Подтверждённые проблемы и изменения
1. **Мигание белой рамки.** Старая таблица CSS Skaz рисовала собственный `::after` за карточкой с другим радиусом, пока Capsule рисовала второй псевдоэлемент. Старое правило удалено, остался один внутренний `box-shadow` с постоянным `.cso-row-focused`; уточнена цель события наведения. Также предусмотрен `root.$` как альтернатива `root.jQuery`.
2. **Не все балансеры отображались.** Список источников формировался исключительно из тех записей, которые прислал сервер. Теперь всегда присутствуют семь пунктов шести разрешённых семейств (Rezka, HDRezka, Alloha, Filmix, Skaz TV, KinoPub, Veo Veo). Неизвестные URL не придумываются: отсутствующий балансер выводится неактивным.
3. **Сброс ручного выбора.** Автоматический резерв мог перекидывать пользователя с выбранного вручную балансера. В сессии отмечается ручной выбор, а автозамена для него запрещена. При попытке выбрать недоступный пункт выбор меню откатывается.
4. **Несогласованные данные доступности.** При повторной записи одного и того же балансера раннее `show:true` могло побеждать позднее `show:false`. Движок и список резервов теперь используют последнее состояние, а порядок выбора сохраняется по первому появлению ответившего источника.
5. **Пустые промежутки при открытии серий.** Отрисовка очищала старый список, а потом ожидала TMDB. Теперь список меняется одной операцией после подготовки карточек; необязательные метаданные имеют дедлайн 850 мс и кэш. Убраны чрезмерно длинные списки неиграбельных карточек.
6. **Долгое ожидание метаданных фильма.** Запрос внешних IMDb/Kinopoisk ID мог предварять поиск до 10 секунд, теперь ограничен 1,8 с и изменяет только известные идентификаторы.
7. **Потеря всех серий из-за одной повреждённой карточки.** `data-json` разбирается отдельно для каждого элемента. Одно исключение не отбрасывает остальные эпизоды.
8. **Ошибки запуска.** Добавлены проверки отсутствующего `file.url`, пустого сетевого ответа, `false` вместо `stream`, несуществующего `quality`, нестроковых значений вариантов качества и невалидных сохранённых фильтров.
9. **Гонки между экранами.** При смене источника и закрытии экрана устаревшие ответы не должны перерисовывать другой источник; при завершении освобождаются таймеры и обложки.
10. **Дублирование и мёртвый код.** Удалены неиспользуемая регистрация стороннего поиска и старые механизмы запоминания балансера. Отдельный движок фильма защищён от повторной инициализации.
11. **Приватность диагностики.** Удалены безусловные `console.log` с данными RCH; сообщения об ошибках каталога выводятся как текст, а не небезопасный HTML.

## Что остаётся риском
- **Совместимость и лицензия:** исходный код Skaz взят из публичной копии, но разрешение правообладателя на распространение полной копии не установлено. Требуется отдельная проверка лицензии.
- **Исполнение удалённого кода:** RCH-протокол Skaz использует команды `eval`/`evalrun`. Они оставлены для совместимости с авторизацией и источниками. Такой механизм нельзя считать безопасным для недоверенного сервера; до публикации широкому кругу пользователей нужен отдельный аудит доверия и ограничений протокола.
- **Нативный Android-плеер:** реальная передача подписанного HLS через Android-мост Lampa/UA Player не воспроизводилась в автоматическом тестовом окружении.
- **Плавность на ТВ:** DOM/CSS-логика и регрессии проверены автоматически, но поведение пульта, стеки WebView и кадровые просадки требуют теста на конкретном устройстве.
- **Сторонние серверы:** каталог Skaz/балансеры могут возвращать ошибки, изменять контракт API, запрещать доступ или ограничивать частоту запросов независимо от локального кода.
- **Общее CSS:** часть исходных правил онлайн-движка исторически остаётся глобальной. Их полная изоляция потребует отдельной совместимой переработки шаблонов без регрессий в других онлайн-плагинах.

## Проверка
CI: `Capsule Online checks` — JavaScript syntax + Node.js регрессионные и поведенческие тесты. Тесты проверяют реальные ветки переключения источников, ручной выбор, список разрешённых провайдеров, защиту от устаревших запросов, разбор эпизодов, выбор качества, ограничение TMDB и Android-маршрут в модели окружения. Успешное CI **не равно** подтверждению реального воспроизведения на ТВ.
