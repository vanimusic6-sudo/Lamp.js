# Capsule Online 0.10.0 — полный пересмотр выбора качества

18 ноября 2026. Код: `capsule-online.js` в `main`. Версия для Lampa: `gh-pages/capsule-online.js`.

## Выявленные причины выбора 720p

1. Раньше режим «Авто» считал неизвестную скорость интернета ограничением 1080p: фактически телевизор без `navigator.connection.downlink` не мог нормально получить 4K. Теперь это **неизвестное значение**, а не низкая скорость. Авто позволяет до 2160p, пока измеренная скорость не указывает на слишком медленное соединение. Ограничение «До 1080p»/«До 720p» работает вручную.
2. Первоначальное ранжирование источника по репутации и озвучке могло предпочесть 720p. Теперь **реальное разрешение и HDR имеют основной вес**; качество оценивается повторно после получения подписанной ссылки.
3. Код использовал таблицу `quality` из одного ответа, иногда пустую, игнорируя карты качества `qualitys` и `quality` из более раннего шага. Новый `filmStreamQuality` объединяет только валидные варианты и выбирает максимальный допустимый, включая `2160p HDR`, `4K`, `UHD`.
4. Раньше поиск прекращался после ограниченного числа голосовых ссылок; внутренняя страница качества Alloha (или другого источника) могла не быть посещена. Теперь источник обходится по ограниченной очереди папок (включая вложенные), даже когда рядом уже есть рабочий 720p.
5. Вложенные signed URL ошибочно получали параметры карточки фильма. Теперь `id/title/serial` добавляются только к корневому поисковому URL, а URL озвучки/качества сохраняются. Для подписанных адресов с `sig/signature/token/hash` не добавляется и `uid`.
6. В объединении ответов `lite/events` и `lifeevents` ссылки зеркал с одинаковым названием балансера затирали друг друга. Теперь сохраняются различные URL одного разрешённого семейства, запросы распределяются round-robin, не давая нескольким адресам Rezka вытеснить Alloha или «Мир кино Z».
7. Каталожное `show:false` само по себе больше не исключает источник фильма, если Skaz всё равно вернул для него URL. Это **попытка проверить**, а не обещание рабочего видео. Неизвестные рекламные агрегаторы по-прежнему исключены.
8. Адреса вида `/lite/...` теперь запрашиваются на сервере Skaz, а не на домене самой Lampa. Поддерживаются также результаты источников, в которых URL видео задан отдельным полем `file`, `stream` или только таблицей качества.

## Как теперь выбирается фильм

- Сначала ищутся варианты **правильного фильма** (ID, точное название, год, по возможности хронометраж), соответствующие выбранному языку.
- Проверяются только 6 разрешённых семейств: Rezka/HDRezka, Alloha, Filmix, Skaz TV, KinoPub, Мир кино Z. Mir Kino Z — только фильмы; Veo Veo удалён.
- Для каждого источника ограниченно просматриваются озвучки, вложенные папки и качества, не выбирая преждевременно 720p.
- Получаются реальные адреса потоков; только **после** этого кандидат получает оценку разрешения, HDR, качества перевода и стабильности источника. 4K HDR побеждает 720p при одинаково подходящем языке и без достоверных признаков слишком медленной сети.
- При расходящихся длительностях используется эталон Lampa/TMDB, когда он доступен; без уверенного совпадения не запускается произвольная версия.
- Запуск выполняет штатный `Lampa.Player.play`, в данных видео выбранный адрес 4K стоит первым, остальные качества сохраняются в меню.

## Ограничения

- Скорость по `navigator.connection.downlink` на большинстве ТВ **неизвестна**, поэтому режим «Авто» теперь может выбирать тяжёлый 4K, который не потянет конкретное устройство/сеть. При торможениях вручную выберите предел «До 1080p» или «До 720p».
- Плагин не может открыть «Мир кино Z», если **Skaz вообще не вернул его в каталоге** для конкретного фильма. Поддержаны распознаваемые псевдонимы `mirkino`, `mirkinoz`, `mir-kino`, `mir_kino_z` и обозначения в заголовках источника.
- Сама работа сервера, CDN, поддержка HEVC/HDR и фактическая аудиодорожка устройства не проверены на ТВ в этой итерации.
- Поиск глубже прежнего и может занимать больше времени (лимит 30 секунд с отменой), особенно при медленных источниках. Задание не остаётся висеть бесконечно.
- В отладке доступен `window.__capsuleFilmLastScan`: безопасные сведения о проверенных семействах, количестве вариантов и выбранном качестве **без токенов и URL**.
